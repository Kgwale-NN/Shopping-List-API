# Shopping List API

A simple REST API for creating and managing a shopping list. It is built with Node.js, TypeScript, and Node's built-in HTTP module.

## Project overview

The Shopping List API helps users keep track of items they want to buy. A user can add an item, view the shopping list, find one item, update its details, mark it as purchased, or remove it.

This project is designed to practise:

- building an HTTP server with Node.js;
- writing strongly typed code with TypeScript;
- working with REST API routes and HTTP methods;
- reading and returning JSON data;
- separating types, controllers, routes, and server code.

## Use-case scenario

Suppose you are preparing to go grocery shopping:

1. Add items such as milk, eggs, and bread to your shopping list.
2. View the complete list before going to the store.
3. Change a quantity, such as increasing milk from one bottle to two.
4. Mark an item as purchased while shopping.
5. Remove an item that you no longer need.

## Core features

| Method | Endpoint | Purpose |
| --- | --- | --- |
| `POST` | `/items` | Create a new item |
| `GET` | `/items` | Return all items |
| `GET` | `/items/:id` | Return one item by ID |
| `PUT` | `/items/:id` | Update an existing item |
| `DELETE` | `/items/:id` | Delete an item |

## Item structure

Each shopping-list item has the following shape:

```json
{
  "id": 1,
  "name": "Milk",
  "quantity": 2,
  "purchased": false
}
```

| Field | Type | Description |
| --- | --- | --- |
| `id` | number | Unique ID generated by the API |
| `name` | string | Name of the item |
| `quantity` | number | Number of items required |
| `purchased` | boolean | Whether the item has been purchased |

## Requirements

Install the following before running the project:

- [Node.js](https://nodejs.org/)
- npm, which is included with Node.js
- [Git](https://git-scm.com/) if you want to clone the repository
- An API client such as the Postman desktop application

Check that Node.js and npm are installed:

```bash
node --version
npm --version
```

## Installation

These commands work in PowerShell, Command Prompt, Terminal, and Git Bash.

1. Clone the repository:

```bash
git clone https://github.com/Kgwale-NN/Shopping-List-API.git
```

2. Enter the project directory:

```bash
cd Shopping-List-API
```

3. Install the project dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

The terminal should display:

```text
the server is running on http://localhost:2000
```

Use `Ctrl + C` to stop the server.

## Available scripts

```bash
npm run dev
```

Runs the server with nodemon. The server restarts when a TypeScript file changes.

```bash
npm start
```

Runs the server with ts-node.

## Using the API

### Get all items

```http
GET http://localhost:2000/items
```

### Get one item

```http
GET http://localhost:2000/items/1
```

### Create an item

```http
POST http://localhost:2000/items
Content-Type: application/json
```

Request body:

```json
{
  "name": "Milk",
  "quantity": 2,
  "purchased": false
}
```

A successful request returns status `201 Created` and the new item.

### Update an item

```http
PUT http://localhost:2000/items/1
Content-Type: application/json
```

Request body:

```json
{
  "name": "Milk",
  "quantity": 3,
  "purchased": true
}
```

A successful request returns status `200 OK` and the updated item. An unknown ID returns `404 Not Found`.

### Delete an item

```http
DELETE http://localhost:2000/items/1
```

A successful request returns `204 No Content` with an empty response body. An unknown ID returns `404 Not Found`.

## Testing with Postman

1. Start the API with `npm run dev`.
2. Open an existing request or create a new request in Postman.
3. Select the HTTP method you want to test.
4. Enter an endpoint such as `http://localhost:2000/items`.
5. For `POST` and `PUT`, select **Body**, then **raw**, and choose **JSON**.
6. Enter the JSON request body and select **Send**.

When using Postman in a web browser, select the **Desktop Agent**. The Cloud Agent cannot send requests to `localhost`.

## Using the API on different devices

### On the same computer

Start the server and use:

```text
http://localhost:2000/items
```

This works on Windows, macOS, and Linux.

### From another phone or computer

1. Connect both devices to the same trusted Wi-Fi network.
2. Start the API on the computer that contains the project.
3. Find that computer's local IP address:

Windows:

```powershell
ipconfig
```

Look for the active network adapter's `IPv4 Address`.

macOS or Linux:

```bash
ifconfig
```

4. Replace `localhost` with that IP address. For example:

```text
http://192.168.1.10:2000/items
```

5. Allow Node.js through the computer's firewall if prompted.

Only expose this learning project on a trusted local network. It does not currently include authentication or production security.

## Important limitations

- Data is stored only in memory.
- All items are lost whenever the server restarts.
- The API does not use a database yet.
- Basic input validation is implemented.
- The API is intended for learning and local development, not production use.
